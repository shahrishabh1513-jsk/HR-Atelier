## 📖 About The Project

**RT_Fashion World** is a fully responsive **fashion e-commerce website** built around a fresh "pastel-season" collection for women and men, with bags, shoes, and jewelry to match. It covers the full shopping journey — browsing by style, filtering by category, saving favourites, managing a bag, signing in, checking out, and tracking an order.

The project was built to practice **real-world storefront UX**: category-driven product browsing, sale and promo-code handling, trust signals (shipping, returns, safe payments, stylist chat), and customer account flows — all in a clean pastel visual identity, using only **HTML, CSS, and JavaScript**.



<div align="center">

| | |
|---|---|
| 🛍️ **Type** | Front-end fashion e-commerce website |
| 🎯 **Built For** | Practicing storefront, bag & account flows |
| 🎨 **Collection Theme** | Pastel-season fashion — women, men, footwear, bags & jewelry |
| 🏷️ **Promo** | Mid-season sale (up to 40% off) + code `RT10` for 10% off the bag |
| 📦 **Core Flows** | Home → Shop → Bag → Login → Checkout → Track Order |

## 🚀 Getting Started

### Option 1 — Use the live version

No setup needed 👉 **[Open RT_Fashion World](https://shahrishabh1513-jsk.github.io/RT_Fashion-World/)**

### Option 2 — Run it locally

```bash
# 1️⃣ Clone the repository
git clone https://github.com/shahrishabh1513-jsk/RT_Fashion-World.git

# 2️⃣ Navigate into the project directory
cd RT_Fashion-World

# 3️⃣ Open index.html in your browser
#    (or use the Live Server extension in VS Code)
```

✅ No build tools, dependencies, or installations required — it's a pure **HTML/CSS/JS** project.
